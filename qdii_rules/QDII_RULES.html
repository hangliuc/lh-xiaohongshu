QDII 基金净值
T+1~2公布
等海外收盘 + 汇率
最晚延迟一天
持 仓 收 益 更 新 的 三 个 层 次
Ⅰ
盘中看到的收益是 估值，非真实净值，基于前一交易日收盘价 × 当前汇率估算
Ⅱ
实际收益以 基金公司公布的净值 为准，通常 T+1 或 T+2 晚更新
Ⅲ
汇率波动 直接影响收益：美元涨 → QDII 多赚，美元跌 → QDII 多亏
汇 率 · 影 响 机 制
人民币 贬值 → 美元资产换回更多人民币 → 收益增加
人民币 升值 → 美元资产换回更少人民币 → 收益减少
汇率每波动 1%，QDII 收益大约同向波动 1%
节 假 日 · 特 殊 规 则
1
海外休市但 A 股开市 → QDII 不更新净值（无交易数据）
2
A 股休市但海外开市 → 基金公司可能延迟公布（非工作日）
3
双方都休市 → 净值不变，恢复交易后更新

SUMMARY · KEY POINTS
QDII 规 则 · 总 结
Everything you need to remember
CORE TAKEAWAY
QDII 的 「慢」 是跨境投资的天性
买之前想清楚 · 卖之后耐心等
五 条 必 记 原 则
Ⅰ
15:00 是生死线：前提交按当天净值，后提交按次日净值，差一天收益可能差很多
Ⅱ
申购确认要等 T+2：比国内基金多冻结一天，期间无法撤单
Ⅲ
赎回到账要 7-10 天：急用钱别赎 QDII，用闲钱投资
Ⅳ
盘中收益只是估值：别被盘中数字吓到或诱惑，以公布的净值为准
Ⅴ
汇率是隐形损益源：QDII 收益 = 市场涨跌 + 汇率波动，缺一不可
