> **当前数据基准**：2026年第2季度报告（截止 2026-06-30，披露截止 2026-07-21）
> **基金池**：20 只 QDII 主动/指数基金（用户在 2026-07-21 指定）

| 字段 | 数据来源 | 获取方式 | URL/API |

## 各字段详细说明

### 1. 基金名称 + 近一年收益率 + 限额

**来源**：天天基金主页 `http://fund.eastmoney.com/{code}.html`

这三个字段从同一个页面获取：

- **基金名称**：解析 `<title>` 标签，如 `华宝纳斯达克精选股票发起式(QDII)C(017437)`
- **近一年收益率**：匹配 `近1年：` 后的 `<span>` 标签数值
- **限额**：解析申购状态区域，按四态校验逻辑处理：

| 显示文本 | purchase_status | purchase_limit | 解读 |
|---------|----------------|----------------|------|
| 开放申购 | 开放 | 无限制 | 正常可买 |
| 限大额(单日累计购买上限 X 万元) | 限大额 | X万 | 大额限购，小额可买 |
| 限大额(单日累计购买上限 X 元) | 限小额 | X元 | 实际接近暂停申购 |
| 暂停申购 | 暂停 | 0 | 完全不能买 |

当限额为"元"且金额 ≤ 1000元时，附加 `effectively_closed: true` 标记。

### 2. 近一年回撤

**来源**：天天基金NAV历史数据API

```
https://api.fund.eastmoney.com/f10/lsjz?callback=jQuery&fundCode={code}&pageIndex={page}&pageSize=20&startDate={start}&endDate={end}
```

**计算方式**：

1. 分页循环获取近1年+40天的全部NAV记录（约240条，QDII基金交易日较少）
2. 按日期排序后，遍历每个交易日：
   - 维护历史最高净值 `peak`
   - 计算当日回撤 = `(peak - 当日净值) / peak`
   - 记录最大回撤值
3. 返回最大回撤百分比

**关键注意点**：该API的 `pageSize` 参数实际无效，每页固定返回20条，必须分页获取全部数据才能准确计算回撤。v1版本因未分页导致回撤严重偏小。

### 3. 市场投资分布（最核心的数据源）

**来源**：中国证监会基金信息披露网站

#### 获取流程（两步走）

#### Step 1 — 搜索季报instance ID

```
http://eid.csrc.gov.cn/fund/disclose/advanced_search_report.do
```

通过基金主代码（A类代码）或基金简称搜索2026年第一季度报告，获取 `uploadInfoId`（即instance ID）。

请求参数（aoData JSON格式）：

```json
[
  {"name": "reportType", "value": "FB030"},
  {"name": "reportYear", "value": "2026"},
  {"name": "fundCode", "value": "012920"},
  ...
]
```

搜索策略：
1. 先用主代码搜索，找不到则用基金简称搜索（部分基金代码在CSRC系统中映射不同）
2. 在返回结果中优先匹配"第2季度/第二季度"报告，若尚未披露则回退"第1季度/第一季度"，再兜底取首条记录

#### Step 2 — 下载并解析季报PDF

```
http://eid.csrc.gov.cn/fund/disclose/instance_show_pdf_id.do?instanceid={instanceid}
```

用 `pdfplumber` 库解析PDF，逐页搜索包含"国家"和"公允"/"比例"关键词的页面，提取"报告期末在各个国家(地区)证券市场的股票及存托凭证投资分布"表格：

```
国家(地区)    公允价值(人民币元)    占基金资产净值比例(%)
美国          4,537,899,084.58     46.00
中国内地      3,261,815,621.87     33.06
中国香港      446,169,804.45       4.52
日本          115,351,930.85       1.17
合计          8,361,236,441.75     84.75
```

**跨页表格处理**：部分基金（如 021662 富兰克林国海亚洲机会）的"国家（地区）"表头出现在一页，数据行跨到下一页。解析器状态跨页保持，遇 `合计` / `注` / 下一节编号（如 `5.`）才结束。

**特殊情况**：

- 017204（华宝海外科技 QDII-LOF）：投资标的以 ETF 为主（ARK Innovation 等美股 ETF），季报"5.2 国家（地区）投资分布"列的是所投 ETF 名称而非国家汇总，故 `market_distribution` 为空。业绩基准为"纳斯达克100×80% + 恒生科技×10% + 中证综合债×10%"，实际暴露以美国科技股为主。
- 017093（景顺长城纳斯达克科技 ETF联接）：2026 Q2 起披露完整持仓，国家分布美国占 97.97%。

### 4. 重仓方向

**来源**：天天基金持仓API

```
http://fundf10.eastmoney.com/FundArchivesDatas.aspx?type=jjcc&code={code}&topline=10&year={year}
```

获取十大重仓股名称，通过关键词匹配推断重仓方向：

| 方向 | 关键词 |
|------|--------|
| 科技巨头 | 英伟达、苹果、微软、谷歌、亚马逊、Meta、奈飞、博通等 |
| 半导体 | 英伟达、博通、AMD、台积电、新易盛、中际旭创、源杰科技等 |
| 新能源车 | 特斯拉、比亚迪、宁德时代、理想汽车、蔚来等 |
| 互联网 | 腾讯、阿里巴巴、美团、拼多多、京东等 |

按关键词命中数量打分，取最高分方向。命中数 ≥ 2 才生效，否则默认"科技"。

## 反爬策略

- 所有请求携带 `User-Agent` 和 `Referer` 头
- 每次请求间随机 sleep 0.5~2.0秒
- 连续3次请求失败主动停止
- 不使用并发请求

---

## 数据更新日期

`update_date` 字段记录数据抓取日期，市场投资分布数据基于 2026 年第 2 季度报告（截止 2026-06-30，披露截止 2026-07-21）。持仓 Top10 同样来自 2026 Q2。
