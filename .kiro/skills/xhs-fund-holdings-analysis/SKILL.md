# 基金持仓分析 · 5 页小红书笔记 Skill

把一只基金做成 5 页深度图文笔记。

## 抓取脚本

本 skill 内置一份 5 页笔记**专用**的抓取脚本 `scripts/fetch.py`，单文件独立可跑：

1. 复制 `scripts/fetch.py` 到 `{topic_folder}/fetch.py`
2. 改顶部 `FUND_CODE`
3. `python fetch.py` → 产出 `data.json`（已自带 `analysis` 派生字段）

产出字段已经精准对齐本 skill 5 页所需，无需任何裁剪：
- `basic` → P1 封面 + P3 任职数据
- `manager` → P3 经理名片 + 头像
- `holdings` → P2 持仓演化（近 4 季 Top10）
- `analysis` → P4 交易习惯（稳定度 / 集中度 / 区域 / 换仓）+ P5 推测素材

⚠ 不要在 `fetch.py` 里增加越界字段抓取（如 PDF 解析、批量筛选、严格跨源校验），保持单文件 = 5 页笔记够用。

## 输出结构

```
{topic_folder}/
├── fetch.py                       # 复制自本 skill 的 scripts/fetch.py
├── data.json                      # fetch.py 产物
├── {PREFIX}.html                  # 5 页合一（基于 example.html 改写）
├── {PREFIX}_01.png ~ _05.png      # 截图产物
└── 小红书文案.md                  # 标题 / 正文 / 标签
```

⚠ **不要在 topic 目录里放 shot.js**。项目根目录有唯一一份通用截图脚本，直接传路径调用即可。

## 5 页结构

```
P1 · 封面：基金名 + 经理 + 关键数据 + 引导语
P2 · 持仓演化：近 4 季 Top10 对比
P3 · 基金经理名片：头像 + 履历 + 4 格数据 + 风格三关键词
P4 · 交易习惯：4 张洞察卡 + 集中度趋势 + 习惯总结
P5 · 下期推测：主结论 + 三条推理依据 + 风险提示
```

## P1 · 封面

- 品牌标识（英文 italic + 中文简称）
- 主标题：基金全名渐变金色 80px + 副标题（类型 + 代码 + 经理名）
- 3 个关键词胶囊（必须从持仓归纳，禁用「优质」「成长」「价值」等空话）
- 三格数据：近 1 年 / 近 3 年 / 成立来收益
- 底部引导虚线框：`← 滑动查看 · {经理}的持仓密码 →`

## P2 · 持仓演化

必须展示完整 Top10 × 4 季度，禁止省略到 Top5。

**双色高亮**：
- 金色 `.q-item.hl`：近 4 季持仓代码的交集（核心底仓）
- 蓝色 `.q-item.new`：最新季新进 Top10
- 其他普通持仓不高亮

**布局参数**（防重叠）：
- 4 列 grid，gap 10px，每列 padding `14px 10px 10px`
- `.q-item` padding `6px 8px`，名称 14px 必须 ellipsis，仓位 16px
- 最新季列加 `.q-col.latest`（红边 + 暗红底）

**底部总结框**：1~2 句话概括「从 X 转向 Y」，必须基于实际持仓变化。

## P3 · 基金经理名片

**头像必须是真实抓取**，不允许占位：
- 源：`http://fundf10.eastmoney.com/jjjl_{code}.html`
- HTML：`<img class="avatar" src="..." alt="经理名">`
- Fallback：抓不到时用 `.avatar-fallback` 显示姓氏，禁用 emoji 占位

**四件套**：
1. 头像（180px 圆）+ 经理名 + 英文 role + 中文头衔
2. 4 格数据：任职回报 / 任职时长 / 管理规模 / 从业年限
3. 经理简历虚线框
4. 投资风格三关键词（Ⅰ Ⅱ Ⅲ）

**三关键词约束**：至少 1 条引用具体持仓事实（如「NVDA/AVGO/TSM 连续四季稳居前三」），禁用「价值投资」「均衡配置」类空话。

## P4 · 交易习惯（重点：禁止套模板）

P4 由 **4 张洞察卡 + 1 个集中度趋势条 + 1 个习惯总结** 组成。

### 4 张洞察卡的选择规则

> **不要套模板。每只基金的"最有意思的 4 个习惯"是不同的，必须基于这只基金的 data.json 自己挑。**

**必选 2 张**（绝大部分基金都适用）：

| 卡名 | 数据来源 | 解读方向 |
|------|---------|---------|
| 核心持仓稳定度 | `analysis.stability_pct` | 几只股票连续四季在 Top10？比例多少？ |
| Top3 集中度变化 | `analysis.concentration` 的 top3 序列 | 集中→分散 / 分散→集中 / 稳定？带 `+/-` pp |

**第 3、4 张：从下面的候选池中挑最有信号的 2 张**

| 候选卡 | 适用基金 | 数据来源 |
|------|---------|---------|
| 全球地理分布 | 全球型 / 海外型基金 | `analysis.region_mix` 或自己拆 美/日/荷/韩/台/A 股 |
| 行业 / 主题分布 | 行业主题基金（半导体 / 新能源 / 医药） | 持仓股票按主题分桶后求和 |
| 上下游产业链分布 | 产业链型基金（光通信、AI、电动车） | 把持仓按"上游材料 / 中游设备 / 下游应用"分桶 |
| 每季换仓股票数 | 换手率高的基金 | `analysis.movements.new_in/new_out` 计数 |
| 最大单仓位变化 | 头部仓位大幅调整的基金 | `analysis.movements.add/reduce` 中绝对值最大那条 |
| 单只持仓波动幅度 | 看持仓激进度 | Top1 仓位最大值 - 最小值（4 季） |
| A 股仓位 vs 海外 | QDII 同时持 A + 海外 | 持仓代码 isdigit 拆分 |
| 大市值 vs 小市值 | 风格鲜明的基金 | 持仓市值或仓位分位拆分 |
| 单一国家集中度 | 全球型基金 | 美股 / 港股 / 日股 / 欧股 占比 |

### 选卡的判断思路

1. 先看 `analysis.region_mix`：如果只有"美股/港股"一项 ≈100%，**就别选 A 股 vs 海外**，没信号
2. 看 `movements`：如果换仓量少（new_in ≤ 1），**就别选换仓股票数**，会被吐槽"这有什么好说的"
3. 看持仓代码组成：如果包含 ≥3 个国家，**优先选地理分布**；如果都是同主题（例如全是芯片），**优先选产业链分布**
4. 看 `concentration`：如果 4 季 Top3 集中度变化 ≥5pp，**Top3 集中度变化卡用"变化方向 + 绝对值"，否则改成 "Top3 平均集中度"**

### 卡片样式

- 普通：默认金色边框
- 上行/激进：`.icard.up`（红边 + 暗红底）
- 下行/稳健：`.icard.down`（绿边 + 暗绿底）
- 每张卡都要 `i-extra` 副文（1~2 行解读），让数字有意义
- 主数字 `.i-v` 用 `DM Serif Display` 82px，单位 `.u` 34px

### 集中度趋势条

4 季 Top10 占比横排 + 趋势箭头（↗ ↘ →）+ 「越来越集中 / 分散 / 稳定」。

### 习惯总结

虚线框：2~3 句归纳经理换仓行为模式，必须基于真实持仓变化，禁用"均衡稳健"类空话。

## P5 · 下期推测（最难写）

**核心要求**：必须独立思考。复述数据 = 失败。

**三条推理依据写作框架**：

| 类型 | 写法 | 反例 |
|------|------|------|
| 行为逻辑 | 从动作推断认知（「降仓但净值创新高 → 主动选择而非被迫」） | 「集中度下降 7%」 |
| 信号识别 | 新进/退出股票暗示什么方向（「Coherent + 日东纺 → 沿光通信向材料端延伸」） | 「新进 2 只股票」 |
| 差异化判断 | 给出和市场共识不同的视角（「Tower 不是先进制程，是 AI 之外差异化」） | 「跟随 AI 浪潮」 |

**禁用模板化表述**：方向已锁定 / 大概率加仓 / 持续看好 / 任何不带具体股票或数字的推测。

**结构**：主推测结论（红色渐变框 36px）→ 三条依据（Ⅰ Ⅱ Ⅲ）→ 风险提示（绿色边框）→ `END · 关注获取下季复盘`

## 派生分析字段映射

`data.json.analysis` 中字段对应到页面：

| 字段 | 用于 |
|------|------|
| `core_stocks` / `stability_pct` | P2 金色高亮、P4 稳定度卡 |
| `movements.new_in` | P2 蓝色高亮、P4 换仓卡、P5 新进信号 |
| `movements.add` / `reduce` | P5 推测素材 |
| `concentration` | P4 趋势条 + Top3 集中度卡 |
| `region_mix` | P4 地理分布卡（仅当 ≥2 个区域） |
| `latest_top5` | P1 关键词归纳来源 |

## 工作流

1. **数据准备**：复制 `scripts/fetch.py` 到 `{topic_folder}/fetch.py`，改 `FUND_CODE`，跑出 `data.json`
2. **复制 example.html** 到 `{topic_folder}/{PREFIX}.html`，**保留所有 CSS class 和结构**，只改文本
3. **逐页填数**：用 `data.json` 数据填内容，禁止伪造任何数字 / 股票名 / 仓位
   - **P4 必须挑卡**：先扫一眼 `data.json`，决定 4 张卡选哪 4 个，再填
4. **截图**：在项目根目录执行 `node shot.js {topic_folder}`（用根目录那份通用脚本，不要复制副本）
5. **逐张 PNG 自检**（见下方铁律）
6. **写文案**：`小红书文案.md`

## 视觉与防重叠铁律

- 画布 1080×1440，每页严格在 1440px 内
- 底部 120px 只允许 disclaimer / watermark / page-num
- 任何 `position:absolute` 元素必须 `z-index`（装饰 ≤1，内容 2，底部 3）
- 长文本（基金名 / 股票名）必须 ellipsis 兜底
- 截图后逐页核对：文字是否覆盖、是否被底部遮挡、是否被 1440 截断
- 有问题优先调 padding > gap > font-size，最后才拆页

## 配套小红书文案

> **核心禁令：禁止复述图片里已经有的内容。**
>
> 反例：「Top1 NVDA 3.65% / Top2 AVGO 3.07% ...」 ← 图片里已经有，文字再写一遍 = 浪费读者时间。
>
> 正确做法：图片是"事实"，文字是"观点 + 故事 + 你的独立解读"。

输出 `小红书文案.md`：

```markdown
# {基金简称} · 小红书文案

## 标题候选（每组 10 个，≤20 字）

### A · 反差 / 悬念风
（用具体数字制造反差："英伟达只有 3.65%？这只 QDII 在搞什么"）

### B · 数据 / 事实风
（不带感情色彩："{经理名} 一年涨 167%，他的持仓变了"）

### C · 个人视角 / 故事风
（第一人称："翻了刘冬最近 4 季报，发现一件事"）

---

## 正文

### 钩子（开头 1~2 句，必须有信息密度）

从这只基金 **最反常识 / 最有反差 / 最值得追问** 的一个点切入。
不要写"今天给大家分享一只基金"这种废话。

### 独立观点（3~5 段，每段聚焦 1 个角度）

不要照搬 P2~P5 的内容。每一段都要回答："读者看完图片 **不知道** 的、但 **应该知道** 的事是什么？"

可选切入角度（挑 3~5 个写）：

- **行为解读**：经理为什么这么做？背后的认知是什么？
- **跨周期对比**：和上一年 / 上一轮风格相比，变了什么？
- **同类对比**：和同类基金（同主题 / 同经理同公司）相比，特别在哪？
- **市场环境**：当前宏观 / 行业背景下，这种调仓意味着什么？
- **风险信号**：哪些地方要警惕？经理的盲区在哪？
- **个人体会**：你作为持有人 / 观察者，看到了什么别人没看到的？

### 经理人话画像（1 段）

把 `manager.profiles[0].bio` 的官方表述翻译成"人话"。
不要堆履历名词，提炼出 1~2 个让读者"记住这个人"的标签。
反例：「2003 年路透 STARMINE 量化分析师，2007 年巴克莱投资管理...」← 这是简历
正例：「22 年从业，在路透做过量化、在巴克莱管过钱，是少数有真海外实战的本土经理」

### 风险提示（必备）

3~4 条，每条具体到这只基金的真实风险，不要写"市场有风险"这种通用话。

### 话题标签

3~5 个：大类 → 主题 → 基金公司 → 场景 → 代码

---
```

### 文案规则

- 标题 30 个候选（A/B/C 各 10），长度 ≤20 字，禁 emoji
- 禁用词：暴涨 / 翻倍 / 稳赚 / 必涨 / 抄底 / 必看 / 一定 / 100%
- **禁止复述卡片内容**：
  - 禁止「Top1 X X%、Top2 Y Y%」这种列表（图片已有）
  - 禁止「核心持仓稳定度 30%」这种照抄数据（图片已有）
  - 禁止「最新一季新进 X 和 Y」这种照抄事实（图片已有）
  - **正文里的每一个数字 / 股票名，必须带"为什么有意思"的解读，否则删掉**
- **禁止任何「数据来源」「数据更新于 X」类标注**（这种元信息只放卡片 disclaimer）
- 风险提示必备
- 话题标签 3~5 个

### 自检清单（写完文案后过一遍）

- [ ] 正文 **没有任何一行** 是"Top X 股票 Y%"的列表
- [ ] 每一段都回答了"图片里没有的"信息
- [ ] 至少有 1 段是"我的解读 / 我的判断"，不是事实复述
- [ ] 钩子第一句不是「今天分享」「跟大家聊聊」这种废话
- [ ] 经理画像不是简历，是有"人感"的标签
- [ ] 风险提示具体到这只基金，不是通用话
